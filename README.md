# Explore: What Learning Type Is This?

**Course:** AI Essentials
**Module:** 4
**Type:** Non-graded exploration activity

## Overview
A quick-classification activity presenting 9 real-world AI application descriptions. Students click to classify each as Supervised, Unsupervised, or Reinforcement Learning, then reveal a single answer key at the bottom with the correct classification and a brief explanation for each. Prepares students for the Module 4 quiz and the problem classification task in the case study.

## File
`index.html`: single self-contained HTML file, no dependencies or external libraries required.

## Instructor Notes
- No student account or login is required.
- The classification buttons and answer key toggle use inline JavaScript; no internet connection is needed for interactivity to function.
- The activity includes 3 supervised, 3 unsupervised, and 3 reinforcement learning examples.
- Examples 5 and 9 are the most nuanced: anomaly detection (unsupervised) can be mistaken for supervised, and a recommendation engine (reinforcement) can be mistaken for supervised due to its use of behavioral signals.
- Reflection is self-assessed only. No submission is expected.
