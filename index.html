Explore: What Learning Type Is This?

Quick Classification Practice

CLASSIFY & COMPARE  |  NO SUBMISSION REQUIRED

Purpose: Not all machine learning systems learn the same way. The type of learning an AI system uses depends on what data is available and what problem it is trying to solve. Recognizing the learning type from a real-world description is a key skill for the Module 4 quiz and the problem classification task in the case study.

What to do: Read each of the 9 AI application descriptions below. For each one, click the button that best matches your classification. When you have worked through all of them, reveal the answer key at the bottom to compare your thinking.

QUICK REFERENCE

Learning Type How It Works Key Signal
Supervised The model trains on labeled examples (input + correct answer) and learns to predict the correct output for new inputs Training data is already labeled with the right answers
Unsupervised The model finds patterns, groupings, or structure in data without any labels or predefined categories No labels; the system discovers structure on its own
Reinforcement An agent learns by taking actions in an environment and receiving rewards for good outcomes and penalties for poor ones Trial and error; feedback comes from the outcome of each action

CLASSIFY EACH EXAMPLE

Example 1

An email provider trains a spam filter using hundreds of thousands of messages that employees previously flagged as either "spam" or "not spam." The system learns which patterns predict spam and applies that knowledge to new incoming mail.

Example 2

A streaming platform analyzes viewing habits across millions of users and automatically discovers natural groupings — such as "binge-watchers of crime dramas" or "weekend documentary viewers" — without anyone defining those categories in advance.

Example 3

A game-playing AI starts knowing nothing about chess. It plays millions of games against itself, receiving a positive signal when it wins and a negative signal when it loses, gradually developing strategies that no human programmer explicitly coded.

Example 4

A bank trains a loan default model using five years of historical applications. Each record in the training data includes the applicant's financial profile and the known outcome: whether the loan was repaid or defaulted. The model uses this to score new applicants.

Example 5

A cybersecurity tool monitors network traffic and builds a model of what "normal" activity looks like. It then flags traffic that deviates significantly from that baseline. The system was never given examples of what an attack looks like.

Example 6

A warehouse robot learns to navigate a fulfillment center floor by trial and error. Each time it completes an order pick without a collision or delay, it receives a positive reward. Each slowdown or near-miss reduces its score. Over time it develops efficient routes on its own.

Example 7

A radiology tool is trained on 50,000 chest X-rays. Each image in the training set was reviewed by a radiologist and labeled as either "pneumonia present" or "no finding." The model learns to replicate those diagnoses on new, unlabeled images.

Example 8

A news aggregation service processes thousands of articles per day and automatically groups them into clusters of related stories. Editors did not define the topics in advance; the system surfaces whatever groupings naturally emerge from the content.

Example 9

A video platform's recommendation engine adjusts what it shows each user based on their real-time behavior. Every time a user watches a full video, it treats that as a positive signal. Every skip or early exit is a negative signal. The system continuously updates its strategy to maximize total watch time.

ANSWER KEY
1 Supervised Each training message carries a label ("spam" or "not spam") provided by humans. The model learns to map input patterns to those predefined labels and applies that mapping to new messages.
2 Unsupervised No one defined the viewer categories in advance. The system finds natural groupings within the data entirely on its own, which is the defining characteristic of unsupervised learning.
3 Reinforcement The AI is an agent acting in an environment (the game board). It receives reward signals based on outcomes (win/loss) and uses those signals to improve its strategy over time. No labeled training data is involved.
4 Supervised The training records each have a known outcome (repaid or defaulted) that serves as the label. The model learns the relationship between financial profiles and those labeled outcomes to predict new cases.
5 Unsupervised The system was never given labeled examples of attacks. Instead, it learns the structure of normal traffic on its own and flags deviations. Anomaly detection without labels is a classic unsupervised application.
6 Reinforcement The robot is an agent that acts (navigates, picks), receives reward or penalty signals based on the outcome of each action, and uses that feedback to improve future decisions. No human-labeled training set is used.
7 Supervised A radiologist labeled each X-ray before training. Those labels are the ground truth the model learns from. Any time expert-labeled examples drive training, that is supervised learning.
8 Unsupervised Editors did not define the topic categories. The system discovers structure within the articles on its own. Clustering without predefined labels is one of the most common unsupervised learning tasks.
9 Reinforcement The recommendation engine acts (serves a video), observes the user's response (watch vs. skip), and treats that response as a reward signal used to update its strategy. This action-feedback-update loop defines reinforcement learning.
